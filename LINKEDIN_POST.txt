The biggest problem with AI coding agents isn't intelligence — it's chronic amnesia, token waste, and the rush-to-edit anti-pattern.

You solve a tricky race condition on Tuesday, and by Thursday the agent repeats the exact same blunder because the context was wiped — or blindly hacks files without understanding the codebase.

I wanted an autonomous software engineer whose knowledge compounds over weeks and plans rigorously before touching code. So I engineered an open-source, pure-C memory, code intelligence, and epistemic planning harness for Pi Coding Agent:

🛡️ Epistemic Plan Gating (pi-quest)
No blind edits. File writes stay locked until the agent investigates, cites file-backed evidence, and passes an independent adversarial subagent review. Diffs must pass real automated test runs before shipping.

🧠 Unified Code Intelligence & Persistent Memory (pi-mm)
Pure-C AST symbol resolution, inbound/outbound call graphs, diff blast radius, and hierarchical memory mipmaps (libcorm + libsepal + liblemma + libislet). Invariants and bug resolutions learned weeks ago are recalled automatically before your prompt hits the model.

⚡ Sub-5ms Reflex Decisions (axil-auren)
Instead of burning tokens asking an LLM "should I remember this?", an in-memory C daemon evaluates reflex decisions via SIMD dot products in ~5ms. 0 decode tokens, $0 cost.

⚙️ Pure-C Efficiency
Algorithmic zero-LLM compaction (pi-vcc) and non-blocking background builds (bg_run) with reactive wakeup in a ~250 MB footprint.

The result is an agent that gets measurably smarter, faster, and more disciplined the longer you work with it.
